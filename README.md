# FedisMinute

Meeting minutes, tasks, votes and signatures for your team. It runs on your own
computer: the data stays with you, and members open it in their browser.

This page only hosts the app downloads and its updates.

## Download

Get the files from the latest release:
**[Releases > Latest](https://github.com/FedisX/FedisMinute/releases/latest)**

| Computer | File |
|---|---|
| Windows (64-bit) | `fedisminute-windows-amd64.exe` |
| Mac with an Apple chip (M1 or later) | `FedisMinute-Mac-M-chip.dmg` |
| Linux (64-bit Intel/AMD) | `fedisminute-linux-amd64` |

## Install

**Windows**: open `fedisminute-windows-amd64.exe`. If Windows warns:
More info > Run anyway.

**Mac**: open the DMG and drag FedisMinute to Applications. The first time,
right-click FedisMinute > Open. If macOS still blocks it: System Settings >
Privacy & Security > Open Anyway.

**Linux**: make the file executable and open it:
`chmod +x fedisminute-linux-amd64 && ./fedisminute-linux-amd64`.

## Updates

FedisMinute checks this page for new versions. With Settings > Automatic
updates on, it installs them by itself; with it off, it asks first. Every
update is signed, and the app refuses any update that is not.
